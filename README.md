# DevOps Practicals

This repository contains all DevOps practicals in a clean, student-friendly format.  
Each practical has its own folder with:

- Clear step-by-step instructions
- Separate code files (ready to copy-paste)
- Commands to run
- Expected outputs

## How to Use

1. Go into any practical folder.
2. Open its `README.md`.
3. Follow the steps.
4. Copy the code files into your project as instructed.

## Requirements (common)

- Python 3.10+
- Git
- Node.js & npm (for React practicals)
- Docker Desktop (for Docker practicals)
- PostgreSQL (for DB practicals)
- VMware / VirtualBox (for VM practical)
- Jenkins + JDK 17 (for CI/CD practical)
